# Quantum Computing, Mapped

A nine-part explainer of quantum computing for software engineers: classical computation as the baseline, the math of qubits and gates, what quantum computers can and cannot speed up, error correction (with a physical-per-logical qubit calculator), who is building the machines, and the state of play in November 2026.

Live: https://idvorkin-ai-tools.github.io/quantum-computing-field-map/

Plain static HTML: `index.html` (hub), `parts/p01.html`–`p09.html`, `paper.css`, `calc.js` (the surface-code overhead calculator on part 6). Current-state claims link to primary sources; company announcements that are not peer reviewed are labelled.
